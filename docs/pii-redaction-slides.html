Engine choice

Sharing is rare, so an AI scan is affordable — and it wins exactly where Presidio is weakest. We already run Gemini Flash for moderation, so it's the same machinery.

The plan

Extend moderation into redaction

  • 1One shared scan function — reuses the moderation machinery, called at all three hooks.
  • 2Find, then strip deterministically. The model only finds PII; our code removes it — no mangling.
  • 3Fail closed. Scan errors → save blocked with a visible error. Never persist a leak.
  • 4No popup. Scrub what's saved; the owner's running agent keeps their data separately.
  • 5Close the moderation gap too — the app paths aren't safety-checked either.
